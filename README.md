# Goal App DB
 
## Run server 
Use Vscode `PHP Server`

> or 

Install PHP in local ( enable `pqsl` extension ) and run PHP Server :
```
php -S locahost:3000
```

## Go 
Public URL : http://144.2.113.93

Local URL ( if server running ) : http://localhost:3000

## Feature
 - Login
 - Create User
 - Display category
 - Complete Goal
 - Uncomplete Goal
 - Complete category
 - Points per user
